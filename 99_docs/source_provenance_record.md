# Official IFLS source provenance record

Checked: 2026-09-05

## Status

The official RAND documentation needed to support the survey-design, wave,
access, and data-use statements has been checked. The local extracted-file
hashes are complete, but the exact official release identifier and the
owner's authorized-access record are still open. No release identity is
inferred from a filename, local path, or SHA-256 hash.

## Primary sources checked

| Source | What it supports | Boundary |
|---|---|---|
| [RAND IFLS landing page](https://www.rand.org/health/surveys/FLS/IFLS.html) | Official survey identity, longitudinal design, wave history, geographic coverage, and the page's current support notice | Does not identify the exact local archive/release used in this project |
| [RAND IFLS Study Design](https://www.rand.org/health/surveys/FLS/IFLS/study.html) | Longitudinal study design, individual/household/community/facility content, and wave timing | Supports study documentation, not a local-file release match |

| [RAND IFLS Data Updates and FAQs](https://www.rand.org/health/surveys/FLS/IFLS/datanotes.html) | Requirement to consult guides/questionnaires, variable units and record multiplicity, skip patterns, special codes, tracking, and PIDLINK guidance | Documentation guidance does not replace a file-level release record |
| [Strauss, Witoelar, and Sikoki, IFLS5 field report](https://www.rand.org/content/dam/rand/pubs/working_papers/WR1100/WR1143z1/RAND_WR1143z1.pdf) | IFLS5 report metadata, recommended wave citations, field/design context, and the seven-volume documentation structure | RAND labels it a working paper; it is not treated as peer-reviewed evidence or as proof of local release identity |

## Claims allowed in the manuscripts

- IFLS may be described as an ongoing longitudinal survey with repeated waves
  from IFLS1 through IFLS5, using the RAND study-design and field-report
  documentation.
- The analysis may cite RAND's documentation for the complexity of units,
  tracking files, PIDLINK, skip patterns, special codes, and the need to read
  questionnaires and user guides.
- The data statement may say that the project does not redistribute IFLS files
  and that users must obtain authorized access and comply with RAND's stated
  conditions.

## Claims not allowed yet

- Do not name a specific official release ID for the local extracted files
  unless it is matched to the source archive and recorded by the data owner.
- Do not claim that a local hash proves download provenance, license, or
  registration status.
- Do not redistribute public-use files, restricted fields, or linked
  derivatives through this repository.

## Required closure before public replication

1. Record the official release identifier and archive/document version used.
2. Record the authorized access/registration evidence without storing private
   credentials or registration tokens.
3. Reconcile the identifier with the local manifest and extracted-file hashes.
4. Confirm the final data statement and wave-specific citations against the
   target journal's current instructions.
